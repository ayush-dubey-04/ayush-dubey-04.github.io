02 · work

featured · 2026

Awadhi Assistant

A chat assistant for Awadhi, a low-resource language, built around one idea: never let the AI guess when verified data is sitting right there. The backend checks an exact-match knowledge base first, falls back to semantic search over a vector store, and only calls an LLM as a last resort — every answer labeled by where it actually came from.

  • Three-tier response pipeline: exact match → RAG semantic search (ChromaDB + Ollama embeddings) → Groq LLM fallback
  • FastAPI backend with Pydantic-validated endpoints for chat, translation, and literature explanation
  • React frontend with source-transparent UI — verified answers and AI-generated ones are never visually confused
